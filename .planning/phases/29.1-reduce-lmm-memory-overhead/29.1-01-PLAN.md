<objective>
Eliminate the redundant 125GB contiguous transpose copy (`np.ascontiguousarray(U.T)`) from all three LMM runners and add kinship cleanup + gc.collect() after eigendecomposition.

Purpose: At 125k samples, U is 125GB. The contiguous transpose copy doubles that to 250GB for zero performance benefit (numpy's CBLAS wrapper already passes CblasTrans for F-contiguous arrays like U.T). Freeing the kinship matrix immediately after eigendecomp and forcing gc.collect() prevents LAPACK workspace memory from overlapping with the LMM association phase.

Output: Four modified files with reduced peak memory and identical numerical results.
</objective>
