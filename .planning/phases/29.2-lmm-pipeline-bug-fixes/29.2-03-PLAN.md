<objective>
Replace the single-read genotype loading in LOCO's _run_lmm_for_chromosome with two-pass chunked column iteration that never allocates the full chromosome genotype matrix.

Purpose: For 100k+ sample datasets, chromosome 1 can have 20k+ SNPs. The current single read allocates `n_valid * n_chr_snps * 8 bytes` (~15GB for chr1 at 100k samples with 20k SNPs). Chunked column iteration caps memory at `n_valid * col_chunk_size * 8 bytes` per chunk, matching runner_streaming.py's two-pass pattern and delivering on the roadmap's "chunked streaming" success criterion.
Output: loco.py with two-pass chunked _run_lmm_for_chromosome that produces identical numerical results.
</objective>

Restructure `_run_lmm_for_chromosome` from single-read to two-pass chunked column iteration, mirroring `runner_streaming.py`'s two-pass pattern. The function currently: (a) reads ALL chromosome genotypes in one call, (b) computes stats, (c) filters, (d) extracts filtered columns, (e) processes in JAX chunks. The new approach: (a) reads chromosome genotypes in column chunks for stats, (b) filters, (c) reads ONLY filtered columns in chunks for association.

**Step 1: Add a `col_chunk_size` parameter to `_run_lmm_for_chromosome`.**

Add `col_chunk_size: int = 5_000` parameter to the function signature. This controls how many chromosome SNP columns are read per disk I/O. Default 5000 means at 100k valid samples the per-chunk allocation is `100k * 5000 * 8 = 4GB` -- much smaller than 15GB+ for the full chromosome.

**Step 2: Compute `valid_indices` for row-filtered reads.**

At the top of the function (after `n_samples = phenotypes.shape[0]`):
```python
valid_indices = np.where(valid_mask)[0]
```

All `bed.read()` calls will use `valid_indices` for row selection, never reading invalid samples.

**Step 3: Replace the single genotype read + stats computation with a chunked stats pass.**

Replace lines 305-343 (the single read, validation, sample filtering, stats computation, and SNP filter blocks) with a column-chunked stats pass:

```python

n_chr_snps = len(chr_snp_indices)
col_means = np.zeros(n_chr_snps, dtype=np.float64)
miss_counts = np.zeros(n_chr_snps, dtype=np.int32)
col_vars = np.zeros(n_chr_snps, dtype=np.float64)
n_unexpected_total = 0

bed_file = Path(f"{bed_path}.bed")
for chunk_start in range(0, n_chr_snps, col_chunk_size):
    chunk_end = min(chunk_start + col_chunk_size, n_chr_snps)
    chunk_col_indices = chr_snp_indices[chunk_start:chunk_end]

    with open_bed(bed_file) as bed:
        geno_chunk = bed.read(
            index=np.s_[valid_indices, chunk_col_indices],
            dtype=np.float64,
        )

    # Validate genotype values
    from jamma.io.plink import validate_genotype_values
    n_unexpected_total += validate_genotype_values(geno_chunk)

    # Compute per-SNP statistics for this chunk
    chunk_miss = np.sum(np.isnan(geno_chunk), axis=0)
    with np.errstate(invalid="ignore"):
        chunk_means = np.nanmean(geno_chunk, axis=0)
        chunk_vars = np.nanvar(geno_chunk, axis=0)
    chunk_means = np.nan_to_num(chunk_means, nan=0.0)
    chunk_vars = np.nan_to_num(chunk_vars, nan=0.0)

    col_means[chunk_start:chunk_end] = chunk_means
    miss_counts[chunk_start:chunk_end] = chunk_miss
    col_vars[chunk_start:chunk_end] = chunk_vars

    del geno_chunk

if n_unexpected_total > 0:
    logger.warning(
        f"LOCO chr genotype validation: {n_unexpected_total} values outside "
        f"expected range {{0, 1, 2, NaN}}"
    )
```
