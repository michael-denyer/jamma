<objective>
Replace the single-read genotype loading in LOCO's _run_lmm_for_chromosome with row-filtered reads that skip invalid samples at read time.

Purpose: For 100k+ sample datasets, chromosome 1 can have 20k+ SNPs. The current single read allocates `n_samples_total * n_chr_snps * 8 bytes` (~16GB for chr1 at 100k), then immediately discards invalid samples. Row-filtering at read time avoids this peak allocation.
Output: loco.py with memory-efficient genotype loading that produces identical numerical results.
</objective>

In `_run_lmm_for_chromosome`, replace the single-read block (lines 305-322) with row-filtered reads using `open_bed` row+column indexing.

**Current code (to replace):**
```python
# Read this chromosome's SNPs from BED file in a single read
bed_file = Path(f"{bed_path}.bed")
with open_bed(bed_file) as bed:
    geno_chr = bed.read(index=np.s_[:, chr_snp_indices], dtype=np.float64)

# Validate genotype values
from jamma.io.plink import validate_genotype_values
n_unexpected = validate_genotype_values(geno_chr)
if n_unexpected > 0:
    logger.warning(...)

# Apply sample filtering
if not np.all(valid_mask):
    geno_chr = geno_chr[valid_mask, :]
```

**New code:**
```python
# Compute valid sample indices for row-filtered reads
# This avoids allocating the full (n_samples_total, n_chr_snps) matrix
valid_indices = np.where(valid_mask)[0]

# Read only valid samples + chromosome columns directly from BED
bed_file = Path(f"{bed_path}.bed")
with open_bed(bed_file) as bed:
    geno_chr = bed.read(
        index=np.s_[valid_indices, chr_snp_indices],
        dtype=np.float64,
    )

# Validate genotype values
from jamma.io.plink import validate_genotype_values
n_unexpected = validate_genotype_values(geno_chr)
if n_unexpected > 0:
    logger.warning(
        f"LOCO chr genotype validation: {n_unexpected} values outside "
        f"expected range {{0, 1, 2, NaN}}"
    )
```

This eliminates:
1. The full `(n_samples_total, n_chr_snps)` allocation
2. The subsequent `geno_chr[valid_mask, :]` copy
3. The `if not np.all(valid_mask)` branch

The resulting `geno_chr` is already `(n_valid, n_chr_snps)`, matching what the old code produced after filtering.

**Compute valid_indices efficiently:** The `valid_mask` is passed as a parameter. Compute `valid_indices = np.where(valid_mask)[0]` once at the top of the function (after `n_samples = phenotypes.shape[0]`), not inside a loop.

**bed_reader compatibility:** `open_bed().read(index=np.s_[row_indices, col_indices])` is supported by bed_reader when both indices are integer arrays or slices. This is already used elsewhere in the codebase (runner_streaming.py uses column slicing). Verify the read produces shape `(len(valid_indices), len(chr_snp_indices))`.

**Remove the old `if not np.all(valid_mask): geno_chr = geno_chr[valid_mask, :]` block** -- it's no longer needed since we read only valid rows.

**Keep everything else unchanged:** SNP statistics computation, SNP filtering, genotype imputation, JAX chunk processing all operate on `geno_chr` which is now `(n_valid, n_chr_snps)` -- the same shape as before.
